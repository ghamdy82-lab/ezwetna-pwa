# عَزْوَتْنَا (Azwetna PWA)
دليل خدمات وأهالي التجمع الثالث المستقل.

## 🔗 رابط الموقع الرسمي (Live Demo)
تقدري تزوري الموقع شغال أونلاين دلوقتي من هنا:
👉 [https://azwetna.web.app](https://azwetna.web.app)

## 📱 نبذة عن المشروع
منصة رقمية خدمية تهدف إلى تسهيل التواصل المباشر بين أهالي "التجمع الثالث" ومقدمي الخدمات المحليين (صنايعية، ورش، أطباء) بدون وسيط، مع لوحة تحكم كاملة لإدارة المحتوى.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Backend & Database:** Google Firebase Firestore
* **Hosting:** Firebase Hosting & PWA Support
